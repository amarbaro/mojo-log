# mojo-log v0.1.0

**Released:** 2026-11-04 · **Commit:** the one tagged v0.1.0 · **Previous:** first release

## What it does

Structured logging for Mojo: levels, key=value fields, text or JSON-lines, stderr, file and journald sinks.

## Highlights

- A disabled call costs one compare (3 ns); an enabled call allocates nothing after the first line.
- 1M JSON lines in about 0.85 s against Python 4.9 s, same 11 MB peak RSS.
- JSON is byte-identical to Python `json.dumps` over 3000 seeded random records.

## Changes

First release, no earlier version.

## Known limits

- Linux. journald needs `libsystemd.so.0`, otherwise skipped at run time.
- Not thread-safe: one `Logger` per thread.
- Stray invalid UTF-8 bytes are not validated, only never a crash.
